# Bayraq Dirəyi

TikTok LIVE üçün brauzer əsaslı oyun və hədiyyə körpüsü.

## İşə salmaq

1. Node.js 20+ quraşdırın.
2. `cd bayraq-live` və `npm ci` işlədin.
3. `npm start -- <TikTok_istifadəçi_adı>` ilə başladın.
4. `http://127.0.0.1:3000` açın.

Hədiyyə ID-ləri oyun panelindən dəyişdirilə bilər; hesab məlumatları repoya daxil edilməyib.
